# OPN Identity Yield

A decentralized yield platform built on OPN Chain that leverages OPN Identity to unlock personalized rewards and staking opportunities.

## Overview

OPN Identity Yield connects decentralized identity with DeFi yield generation.

Users can:

* Connect OPN Identity
* Stake assets
* Earn yield rewards
* Build on-chain reputation
* Unlock higher reward tiers

## Features

### Identity-based Yield

Reward rates are influenced by verified on-chain identity and engagement.

### Staking

Stake supported assets to earn yield.

### Reputation Score

Track participation and governance activity.

### Governance

Community-driven decision making through token voting.

## Smart Contract

Deployed on OPN Chain Testnet.
